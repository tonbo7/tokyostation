出典とライセンス

このサイトのデータは、すべて公開されているオープンデータです。どこから取ってきて、どういう条件で使えるのかをここに書いています。 くわしい一覧は DATA_SOURCES.md にもあります。

🚦 運行情報・バス・シェアサイクルについての注意

このデータは 公共交通オープンデータセンター（ODPT） がまとめて公開しているものです。各事業者が直接このサイトに出しているものではありません。

内容が正確・完全であるとは限りません。表示には必ず「取得時刻」を付けています。古い情報を現在の状況として出すことはせず、取れないときは「取得できませんでした」と表示します。

このサイトの表示について、鉄道・バス・シェアサイクルの事業者に直接問い合わせないでください。問題や質問は GitHub の Issues へお願いします。

ODPT の API キーはサイトのファイルには入っていません。自分のキーを使う場合は「🚦 いまの状況」パネルで端末のブラウザにだけ保存されます。

公共交通（いまの状況）

データ出どころライセンス・条件使い方
鉄道の運行情報（odpt:TrainInformation）公共交通オープンデータセンター（JR東日本・東京メトロ・東京都交通局 ほか各社提供）公共交通オープンデータ基本ライセンス。出典表示比較ビューの電車の案・駅カード・🚦パネル。3分で期限切れ
バス停・系統・走っているバス（odpt:BusstopPole／BusroutePattern／Bus）公共交通オープンデータセンター（東京都交通局 ほか）同上東京駅から約650mだけ。位置は1日、バスの位置は2分で期限切れ
シェアサイクルのポートと台数（GBFS）公共交通オープンデータセンターの公開URL（ドコモ・バイクシェア、HELLO CYCLING 提供）各提供元の公開データ。出典表示東京駅から約1kmだけ。台数は2分で期限切れ

ODPT が提供するデータの利用条件は 公共交通オープンデータセンターの利用規約 で確かめてください。鉄道会社・バス会社のロゴやマークは使っていません。

使っていないもの

鉄道会社・バス会社・チェーン店のロゴ画像（商標・著作権）、グルメサイトの評価点（利用規約）、商用予約サイトの在庫データ。 くわしい理由は DATA_SOURCES.md と README にあります。

まだ載せていないもの（スコープ外）

ほこナビ歩行空間ネットワークデータ（国土交通省仕様）を読み込む仕組みは入っていますが、データ本体は同梱していません。 data/indoor/README.md の手順でデータを置くと、歩ける道の歩きやすさとエレベーター・階段・トイレの位置が出ます（出典・取得日はそのときに追記）。 屋内地図（通路の形・店舗）は未着手です。乗車位置は駅カードの「駅構内」（data/details/<駅名>.js・現地調査）で扱っています。
