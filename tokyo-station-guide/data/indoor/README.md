# 東京駅周辺の歩行空間・構内データ（ほこナビ）

このフォルダに **歩行空間ネットワークデータ**（国土交通省仕様）を置いて
`tools/build_indoor.py` を実行すると、`data/indoor.js` ができて、

- 地図を拡大したとき、歩ける道が「歩きやすさ」の色で出る
  （緑＝段差なし／黄＝段差・急な坂・狭い／赤＝階段／青＝エレベーター・エスカレーター）
- 🛗 構内・歩行空間 のスポット（エレベーター・階段・トイレなど）が地図に出る
- 東京駅周辺の駅カードに「🚶 歩きやすさ・構内」のまとめが出る

ようになります。**データ本体はこのリポジトリに入れていません**（配布元の条件を確かめてから使ってください）。

## 手順

1. データを手に入れる
   - ほこナビ（国土交通省 バリアフリー・ナビプロジェクト） https://www.hokonavi.jp/
   - G空間情報センター で「歩行空間ネットワークデータ 東京駅周辺」を探す https://www.geospatial.jp/
   - 仕様: 「歩行空間ネットワークデータ等整備仕様」（国土交通省）
2. GeoJSON（WGS84）にして `data/indoor/raw/` に置く
   - Shapefile のときは QGIS か `ogr2ogr -f GeoJSON -t_srs EPSG:4326 out.geojson in.shp`
   - リンク（線・`link_id` あり）、ノード（点・`node_id` あり）、施設（点）の3種類をそのまま置けます
   - `raw/` は git に入りません（`.gitignore`）
3. 実行する

   ```
   python3 tools/build_indoor.py --fetched 2026-10-05
   node tools/build_bundle.js      # 単一ファイル版も作り直す
   ```

4. `data/indoor.js` と、`DATA_SOURCES.md`・`credits.html` の出典欄（取得日・ライセンス）を更新してコミットする

## 気をつけること

- **属性コードの意味は仕様書で確かめてください。** `tools/build_indoor.py` の `CODES` に、階段・エレベーター・段差・勾配・幅員の番号をまとめてあります。版が違うと番号が違うことがあります
- 東京駅から 900m 以内だけを残します（`--radius` で変更）
- 整備時点の情報です。工事などで変わることがあるので、画面には「整備時点」と出典を出しています
- 屋内地図（通路の形・店舗）は含みません。ここで扱うのは「歩ける道の性質」と「設備の位置」だけです
